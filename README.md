# Bharath Krithick - Portfolio Website

This repository contains the complete personal portfolio website for **Bharath Krithick**, Senior Associate - Accounts, Risk & NBFC Compliance.

## How to use with GitHub Pages:
1. Upload `index.html` to your GitHub repository root (`/`).
2. Save your preferred photo as `profile.jpg` in the same repository folder.
3. In your repo: **Settings** -> **Pages** -> Select branch **`main`** / **`(root)`** -> Click **Save**.
4. Your website will be live in 1-2 minutes!
